The brand signature — the full name in letter-spaced display caps; there is no logo mark, so this stands in for one everywhere.

```jsx
<Wordmark size="lg" />
<Wordmark size="sm" inverse />           {/* over a photographic hero */}
<Wordmark name="MERT TÜRELI" as="a" href="/" size="md" />
```

Sizes `sm | md | lg | xl` step both size and tracking (tracking loosens as the mark gets smaller). Never set it in sentence case, never pair it with an invented glyph.
