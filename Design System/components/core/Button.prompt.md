Mono caps action in a pill; the underlined `link` variant is the inline form used at the end of copy blocks.

```jsx
<Button variant="solid" trailing="→">View the work</Button>
<Button variant="outline" size="sm">Download CV</Button>
<Button variant="glass">Read more</Button>   {/* over a photographic hero */}
<Button variant="link">All projects</Button>
```

Hover darkens (solid) or inverts (outline); there is no press-shrink and no shadow. Use `glass` only on top of imagery.
