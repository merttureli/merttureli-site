Privacy

What this site measures

This is my personal site. It runs basic analytics so I can tell whether the work is landing and which applications people are arriving from.

What is collected. Pages viewed, how long the page was open and visible, how far it scrolled, which sections stayed on screen long enough to read, and clicks on links such as the resume, contact card, email, phone, and project pages. For links that leave the site, only the name of the other site is kept. Your browser also reports its language, screen size, and time zone, and the referring site if you arrived from a link. When a link I sent includes a short code in the address, that code is recorded so I know which application or message the visit came from.

Visitor ID. The site stores a random visitor ID in your browser's local storage so repeat visits can be linked, and a second random ID in session storage for the current tab. It also keeps any link code from the address for up to 30 days, so a later visit still counts toward the right message. These are not cookies and hold nothing about you. Clearing site data for merttureli.com removes them.

Who receives it. These measurements go to a collector I run on Cloudflare Workers, which sees the network your request came from (the internet provider or company network name) and the approximate city, as any web request does. Your IP address itself is not stored.

Microsoft Clarity. The home page and the project pages also load Microsoft Clarity, which records page interactions such as scrolling, clicks, and pointer movement so I can replay how a visit went. Clarity sets cookies named _clck and _clsk on this site, and Microsoft may set its own cookies from clarity.ms. The link code, if any, is attached to the replay. Clarity is not loaded on the website inquiry page or the contact card page. Microsoft's practices are described in their privacy statement.

Website inquiries. If you choose to send a meeting request, I receive the name, email, project details, preferred date, time preference, and timezone you provide. Formspree processes and stores the submission and forwards it to my inbox so I can reply. Read Formspree's privacy policy for how it handles submissions. A request does not book a meeting automatically. Analytics on that page record only that the form was opened, which step it reached, and whether the request was sent or failed.

What is not collected. Analytics do not collect names, email addresses, or the contents of the inquiry form. There are no visitor accounts or advertising, and I do not sell personal information.

Opting out. If your browser sends Global Privacy Control or Do Not Track, neither the analytics nor Clarity loads, and no visitor ID is created or read. A content blocker also works. Cookies and IDs stored on an earlier visit stay until you clear site data. These settings do not stop an inquiry you choose to submit. To request removal of information associated with your visit or inquiry, email merttureli0@gmail.com.
