Engine

Every value is one getBoundingClientRect read per target, taken in a single pass before any write. Millimetres are CSS px × 25.4 / 96. On touch, hold any marked element for 500 ms to dimension it alone for 3 s. At tier 1 the engine recomputes at most every 100 ms while scrolling and at tier 0 only when the scroll rests; between recomputes it carries the overlay by the scroll delta.
