Part 1 / merttureli.com

SiteThe home page and case studies are built from design-system components (_ds/) and rendered to static HTML by tools/build.py. The websites page uses the same look as plain .ds-* classes.

Palette, css/site-palette.css

S01#site-header

Site header

Wordmark left, four section links right, a Menu button below 861px. Floats transparent over the dark hero on the home page and case studies; sits on a hairline on the websites page.

Used in
index.html, projects/*.html, websites.html
Built from
SiteHeader (_ds), hover in css/interaction-polish.css, phone rules in css/mobile.css, .ds-header in css/websites.css
Edit
Links: nav in the renderVals() of src/index.html; case pages: NAV in build-case.py

Variants

  • inverse="true" white type over a dark hero; omit for ink type on paper.
  • floating="true" absolute, no hairline. Omit to sit in flow on a hairline.
  • aria-current="page" on a .ds-nav link keeps its underline.

Do

  • Keep the same four links in the same order on every page.
  • Point case-page links back to ../index.html#section.

Don't

  • Edit the built header in index.html; it is regenerated.
  • Add a fifth link; the phone menu and the desktop row both assume four.

S02#site-button

Button

The pill call to action: mono caps, a trailing arrow that nudges 3px on hover, and a 2px lift from css/depth.css. Glass over dark plates, outline on paper.

Used in
Home hero, every work entry, contact; case-study heroes and footers; websites page; home Websites block
Built from
Button (_ds), [data-depth-button] in css/depth.css, hover in css/interaction-polish.css; .ds-button in css/websites.css; .websell-cta in css/website-entry.css
Edit
Home: src/index.html. Case pages: button() in build-case.py

Variants

  • glass only over dark plates or photos.
  • outline on paper and on .on-dark sections (tokens flip).
  • solid, ghost, link exist in the DS but are unused today.
  • Always pass data-depth-button with the same value as variant.

Do

  • Two to four words, sentence case in the source (CSS sets caps).
  • Use → for in-site links and ↗ for a page that opens elsewhere.
  • One primary button per block.

Don't

  • Add shadows, colors or a press effect. Hover inverts and lifts, nothing else.
  • Use glass on white paper.
  • Write the inline styles by hand on the home page; use the template.

S03#site-meta

Meta label and caption

Small mono caps for everything measured or filed: eyebrows above headings, the credit line under a title, captions under media. An optional index (01, a) prints in full ink before the text.

Used in
Every section of the home page and case studies; .ds-meta and .ds-index on the websites page
Built from
Meta, Caption (_ds); [data-depth-label] color in css/depth.css
Edit
src/index.html; case pages: meta() in build-case.py

Variants

  • tone: default meta gray, muted, strong (full ink), body.
  • wide="true" opens tracking to 0.32em for eyebrows.
  • data-depth-label lets the label follow .on-dark and the palettes.

Do

  • Separate parts with / and spaces.
  • Zero-pad indices: 01, 02.
  • No full stop on a label or caption.

Don't

  • Put sentences in a label; that is a paragraph.
  • Use a label as the only heading of a section; pair it with a display heading or a rule.

S04#site-rule

Section rule

A hairline with a mono label on the left and a numeral on the right. It titles a section; with data-heading="2" the build turns the label into the section's <h2>.

Used in
Home About, What I work with, Contact; every case-study section
Built from
Rule (_ds), [data-depth-rule] in css/depth.css
Edit
src/index.html; case pages: rule() in build-case.py

Variants

  • right numeral, optional; zero-padded (01, 006).
  • data-heading="2" or "3" sets the heading level of the label.
  • strong draws the line in full ink (unused today).

Do

  • Open each content section with one rule.
  • Keep the label to one to three words.

Don't

  • Stack a rule directly on top of a border-top; one line per edge.
  • Skip data-heading on a section that has no other heading.

S05#site-heading

Display heading and body

Archivo caps at 0.92 line height, four sizes. level sets the size only; as sets the element. Body copy is a plain <p> with the body tokens.

Used in
Every title on the site. Home h1 is the name (Archivo Name, set in the head of src/index.html)
Built from
DisplayHeading (_ds), sizes --fs-display-1..3, --fs-title-1; .ds-display, .ds-title, .ds-lead in css/websites.css
Edit
src/index.html; case pages: heading(), para() in build-case.py

Variants

  • level 1 (hero), 2 (section), 3 (sub), 4 (work entry title).
  • treatment="inverse" white on dark; outline exists, unused.
  • Case titles of 10+ letters a word drop to level 2 (title_level()).

Do

  • Two to four words, one <br> at most.
  • Keep one h1 per page.
  • Cap body copy at --measure.

Don't

  • Pick a level for its element; set as for that.
  • Use mid sizes for emphasis. Big or small, little between.

S06#site-spec

Spec list

Mono key and value rows on hairlines. The most repeated device on the site: project facts, About details, contact rows.

Used in

Built from
SpecList (_ds); phone columns in css/mobile.css
Edit
Rows live in renderVals() (chargerSpecs, aboutSpecs) in src/index.html; case pages: brief in the content JSON

Variants

  • A row can carry aside, a third muted value on the right.
  • columns overrides the grid; case pages use two columns.
  • dense drops the hairlines (unused).

Do

Don't

  • Hand-write rows in the markup; edit the data list.

S07#site-media

Media frame

A photo with grain, 8px corners, the mounted-print shadow from css/depth.css and an indexed caption under it. The image edge is the card edge.

Used in
Home work entries (Robo-Catcher pair), Beyond; case-study galleries
Built from
MediaFrame + Grain (_ds), figure > div:first-child rules in css/depth.css
Edit
src/index.html; case pages: a section's frames in content/projects/<slug>.json

Variants

  • ratio: 3 / 2 default, 4 / 3, 4 / 5 portrait.
  • scrim: hero, bottom, flat when type sits on the photo.
  • grain="false" for screenshots.

Do

  • Write real alt text; credit photographers in the caption.
  • Make derivatives first: python3 tools/media.py image.

Don't

  • Add a border, fill or shadow of your own.
  • Expect hover-zoom to scale; css/depth.css pins it to a 1.5% lift on purpose.

S08#site-stage

Render stage

An inset 14px tray for transparent CAD renders and turntable videos. The video waits for js/media-playback.js: poster first, then the source size that fits the screen, paused offscreen.

Used in
Home work entries (HOTBOX, Robo-Catcher, bend fixture, pedals, Therma-Shift); case-study heroes
Built from
.depth-stage in css/depth.css; video contract in the header of js/media-playback.js
Edit
src/index.html; case pages: clip and clip_sizes in the content JSON

Variants

  • aspect-ratio 16 / 9, 4 / 3 or 5 / 4 to fit the render.
  • Inside .depth-hero the tray turns transparent with a floor shadow.
  • Opaque renders: add an mp4 <source> after the webm.

Do

  • Always set data-poster; it shows when motion is off.
  • Ship -1280 and -960 sizes: python3 tools/media.py video.
  • Blur and pill anything under NDA.

Don't

  • Use src or autoplay; the script decides when to load.
  • Put opaque photos in the tray; use a media frame.

S15#site-flag

Copy flag

Built from

Edit

Variants

Do

Don't
